# ErsatzTV

ZevTV uses ErsatzTV as the planned linear-TV playout system.

## Channel lineup

1. ZevTV Local
2. ZevTV News
3. ZevTV Weather
4. ZevTV Sports
5. ZevTV Music

The media folders and schedules can be configured in ErsatzTV after the server is running.

## Linux

The ZevTV ErsatzTV server is intended to run on the Debian 13 x86_64 WSL environment used for development.

Default ErsatzTV web UI:

`http://localhost:8409`
