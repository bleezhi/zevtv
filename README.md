# ZevTV

ZevTV is a local IPTV / linear-TV project for the Zev ecosystem.

## Branding

The official vector logo is in [branding/zevtv.svg](branding/zevtv.svg).

The SVG is intentionally vector-based so it can be converted to PNG at any resolution without losing quality.

## ErsatzTV

The planned backend uses ErsatzTV for scheduled linear channels, media libraries, playouts, M3U and XMLTV/EPG integration.

More setup notes are in [ersatztv/README.md](ersatztv/README.md).
